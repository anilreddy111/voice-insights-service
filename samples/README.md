# Sample audio

## Synthetic (plumbing tests)
- `female_like_220hz.wav`, `male_like_120hz.wav` — generated by
  `python scripts/make_sample.py`. NOT real voices; useful only to exercise
  decode/VAD/API paths. The quality gate correctly reports `insufficient`
  for these because Silero-VAD rejects non-speech signals.

## Real speech (LibriSpeech dev-clean, CC BY 4.0)
- `librispeech_female_1462.wav` — speaker 1462 (F)
- `librispeech_male_3000.wav` — speaker 3000 (M)

Source: https://www.openslr.org/12 (Panayotov et al., 2015), license CC BY 4.0.
Read speech from LibriVox audiobooks; see LibriSpeech SPEAKERS.TXT for
speaker identity/attribution.

```bash
curl -F "file=@samples/librispeech_female_1462.wav" localhost:8000/analyze
# -> gender female @ ~0.98, age_bracket 31-45, ~140ms
```
